# The public API of 1.0: a review of every public type

Condition 4 of 1.0 asks for the public API to be decided once, because after 1.0 a public type can only be
removed in the next major version. This table is that decision for each of the 261 public types of the 28 runtime
packages of 0.10.1, with the reason.

## The rule

A type stays public only if at least one of these holds:

1. the guides, or the capability catalogue, document it;
2. the template, a skill or a reference sample uses it;
3. it appears in the signature of a kept member (a parameter, a return type, a base type, an attribute);
4. it is a documented extension point that a product implements. A decision record documents a type when it names it
   as an extension point, or as an entry point a product calls; a decision record that only describes the framework's
   own mechanism does not.

Otherwise it becomes internal. A type that other MP Core packages use is shared with them through
`InternalsVisibleTo`, which is safe because the packages of a cohort ship under one version (ADR-010).

## The result

| Decision | Types |
|---|---|
| keep | 226 |
| make internal | 35 |
| remove | 0 |

Of the members of the kept types, 2 became internal; they are listed after the types.

The members of a kept type are kept with it. `PublicAPI.Shipped.txt` of each package lists the reviewed API, member by
member, and is the promise of 1.0 (ADR-020).

## Members

The rule applies to a member as well as to a type. The members of an interface, an enum, a record and a struct are the
contract of their type and were not weighed one by one. The 472 public members of the kept classes were: 393 are named by a
guide, a decision record, the template, a skill or a reference sample, and 79 are named nowhere outside the source and the
tests. Those 79 were read one by one. **Of the 79,
48 are members of option classes and 9 are limits or defaults; of the other 22, 9 implement a kept interface, 11 are the builder,
result and helper methods of kept types that products call, and **2 became internal**, listed below.

## How a break is recorded

Each type made internal is a break against 0.10.1, the last published version. Package validation reports it as
CP0001, and `src/<package>/CompatibilitySuppressions.xml` records it, with the reason of this table above the entry.
A test holds the two together: every type made internal has a suppression, every suppression has a row here, and
every type in a `PublicAPI.Shipped.txt` has a row that keeps it. The file is removed with the release of 1.0.0, which
becomes the baseline.
