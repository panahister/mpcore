# Visual assets

The MP Core diagrams are repository-native SVG files generated by `eng/diagrams/mpcore.py` and the
shared drawing kit in `eng/diagrams/draw.py`. Every README diagram has light and dark variants.

`social-preview.svg` is the editable repository-card source and `social-preview.png` is the 1280 × 640
upload-ready GitHub social preview. The visual language and repository relationships are documented in
[`../architecture/ecosystem.md`](../architecture/ecosystem.md).

Keep public artwork within the cool-spectrum MP palette. Do not add private design identifiers,
consumer branding, secrets, or externally hosted dependencies.
